# Public API documentation is part of the plan

When planning work, consider what should be documented in the public API documentation and what should not. This determination of
"what part of behavior is the API contract" should be part of the plan. Discover any ambiguities and resolve them in the planning phase.

Non-public API documentation does not need to be represented in a plan and may be created on the fly as part of feature development
unless otherwise specified by the user.
